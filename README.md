### Александр

Выпускаю продукты с ИИ-агентами и внедряю ИИ в работу компаний: боты для заявок и документов, поиск по базе знаний, связка с CRM. До запуска меряю качество на настоящих примерах и показываю, где система ошибается.

- [**demo-rag**](https://github.com/tavriq/demo-rag): бот по Трудовому кодексу, [живое демо](https://rag.tavriq.ru). Ответ ссылается на нужную статью в 39 из 43 тестовых вопросов. Свой MCP-сервер из двух инструментов подключает бота к Claude Code одной командой.
- [**agent-gates**](https://github.com/tavriq/agent-gates): сервис на FastAPI, который агент пишет под хуками-гейтами и независимым LLM-судьёй. На сами гейты 59 тестов, в том числе на найденные обходы.
- [**demo-n8n**](https://github.com/tavriq/demo-n8n): разбор входящих заявок на n8n, [живое демо](https://n8n.tavriq.ru). Категорию определяет верно в 40 из 42 заявок, срочность в 34 из 42. Телефон и почту клиента скрывает до отправки в модель.
- [**claude-setup**](https://github.com/tavriq/claude-setup): моё окружение Claude Code (правила, субагенты, скиллы) в установщике на одну команду.

Остальные проекты и разбор каждого с замерами: [tavriq.ru/about](https://tavriq.ru/about/?r=gh).
